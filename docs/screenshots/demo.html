CIS 18.9.11 WN11-EP-000010 NIST 3.13.10
Manual
  1. Click Admin PowerShell — this opens an elevated PowerShell window and sets the three required GPO registry keys automatically (UseAdvancedStartup=1, UseEnhancedPin=1, UseTPMPIN=1).
  2. In the elevated PowerShell window, run: manage-bde -protectors -add C: -TPMAndPIN
  3. When prompted, enter a PIN of your choice (alphanumeric PINs supported if Enhanced PIN GPO is enabled).
  4. Verify the protector was added: manage-bde -protectors -get C:
  5. Restart the machine. You will be prompted for the PIN at boot.
